# Банк

Банк — организация, которая работает с внутриигровой валютой сервера — Алмазной Рудой (АР). Банкиры обслуживают счета игроков, проводят операции с АР и помогают с оформлением сделок.

<Alert type="info">
Все расчёты ведутся только в Алмазной Руде — это единственная разрешённая валюта на сервере. Подробнее в [правилах](/wiki/rules).
</Alert>

## Как вызвать банкира

Открыть меню банка и вызвать банкира можно командой:

```
/bank
```

## Банковская карта

Каждому счёту соответствует банковская карта. Владельцы подписки [Ветерок+](/wiki/wind_plus) получают выбор кастомного дизайна для карточек в банке.
